# ClassRecord v0.2.0 — 需求分析与 Release 信息

- **发布日期**：2026-09-09
- **版本号**：versionName `0.2.0` / versionCode `4`
- **定位**：测试版本（0.x 为测试版体系；此前 v0.1.0 为最初内测版本）
- **Git 标签**：`v0.2.0`

## 一、项目背景

课堂/会议场景下，人工记录要点成本高、易遗漏。ClassRecord 旨在提供「录完即得」的课堂记录助手：录音上传或实时录制后自动完成语音转写、内容总结，并支持针对课堂内容的追问。系统采用自托管架构（FastAPI 后端 + React 前端 + Docker 部署），数据不出服务器。

## 二、功能需求

### 1. 录音上传与转写

- 支持常见音视频格式上传（webm/wav/mp3/m4a/ogg/mp4）
- 按语言自动路由识别模型：
  - 中文/粤语 → **SenseVoice-small**（int8 ONNX，本地推理）
  - 英/日/韩 → **Whisper large-v3**（faster-whisper，GPU）
- 转写完成后自动生成课堂总结，状态全程可视化（转写中 → 总结中 → 已完成）

### 2. 实时流式录制（核心特性）

- 浏览器/App 通过 WebSocket 持续推送音频块，服务器增量转写
- **锚定窗口滑动转写**：长课堂（1 小时以上）转写耗时恒定；文本只增不减，支持「逐字更新 + 对前文修订」的实时效果
- 转写间隔 3 秒，端点检测静音 1.2 秒收句
- 转写文本累积到阈值后自动生成分段小结
- 录制结束后自动生成整课总结
- 切后台保活：安卓前台服务 + 通知栏实时展示录制时长与最新转写

### 3. 语言与场景增强

- 录制/上传前可选识别语言（中/粤/英/日/韩）
- 场景预设（默认/计算机/思政/数学/英语），为 Whisper 路径提供热词与提示词偏置

### 4. 记录管理

- 记录列表（搜索）、详情页（总结/转写原文/分段小结/提问四个 Tab）
- 针对转写内容的 AI 追问（QA），历史问答持久化
- 复制内容、导出 Markdown、删除记录
- 处理失败自动展示原因并支持一键重试总结

### 5. 多端与账号

- Web（响应式，桌面横排布局）、安卓 App（Capacitor 远程壳模式）、iOS
- Zitadel OIDC 登录，服务端 Session；多设备同账号数据互通
- 深色/浅色主题切换、下拉刷新、页面过渡动画

## 三、非功能需求

| 维度 | 要求 |
|---|---|
| 性能 | 实时转写端到端延迟 ≤3s；长录制不随时长劣化 |
| 隐私 | 语音与文本全部自托管处理，不经过第三方 API |
| 轻量化 | 移除端侧离线识别模型（sherpa-onnx 安卓/iOS），APK 从 96MB 降至 4MB |
| 部署 | Docker Compose 一键部署，GPU（NVIDIA）可选加速 |
| 音频规范 | 16kHz 采样率；增量解码（seek 断点续解）避免整文件重解 |

## 四、版本内关键决策与演进

1. **架构收敛**：从端侧离线识别（sherpa-onnx 安卓/iOS 双端）演进为「所有设备统一音频推流 + 服务器转写」，原因：国产 ROM 缺系统语音识别服务、服务器转写效果已足够出色
2. **实时转写重构**：修复文本替换丢内容、一句话重复转写、越录越慢等问题，确立锚定窗口架构
3. **多设备状态**：修复僵死录制导致「正在由其他设备录制」误显示（状态清理 SQL 大小写根因）

## 五、Release 信息

- **Tag**：`v0.2.0`
- **APK**：`classrecord-0.2.0.apk`（约 4MB）
- **已知限制**：
  - 中文路径无热词增强（SenseVoice 模型不支持上下文偏置）
  - 录制中断会产生多条记录，需手动分开查看（合并功能在 v0.3.0 提供）
  - 无应用内更新通道，需手动安装新 APK
