# ClassRecord v0.3.0 — 需求分析与 Release 信息

- **发布日期**：2026-09-14
- **版本号**：versionName `0.3.0` / versionCode `5`
- **定位**：测试版本（0.x 为测试版体系）；**应用内更新服务的引导版本**（此后版本升级不再需要手动安装）
- **Git 标签**：`v0.3.0`

## 一、版本目标

v0.2.0 投入使用后暴露出三类真实痛点，构成本版本的需求来源：

1. **内容分发难**：课堂总结需要分享给同学/同事，但查看者必须注册登录
2. **录制中断代价高**：网络波动/误退出导致一节课拆成多条记录，无法拼回
3. **课堂节奏控制**：课间休息时录制无法暂停，产生大量无意义内容；且长时间连续录制难以中途管理
4. **更新渠道缺失**：自托管分发没有 Play 商店通道，用户升级全靠手动重装
5. **处理粒度粗**：部分场景只需转写文本，不需要每次都消耗 LLM 生成总结

## 二、功能需求

### 1. 记录重命名

- 详情页标题旁编辑按钮，行内修改，回车保存/Esc 取消
- 接口 `PATCH /api/recordings/{id}`，录制中的记录不可改名

### 2. 限时分享链接（免登录查看）

- 详情页「分享」面板生成随机 token 链接，有效期 24 小时 / 3 天 / 7 天
- 访问者无需登录 Zitadel，只读查看总结 / 分段小结 / 转写原文，复用现有深色主题与 Markdown 渲染
- 支持复制链接、重新生成（旧链接立即失效）、随时撤销
- 公开接口 `GET /api/share/{token}` 不挂认证依赖，过期返回明确提示
- 安全设计：token 仅在生成时展示一次，刷新页面后不回显（防泄露），但仍可撤销/重建

### 3. 记录合并

- 列表页多选模式，勾选 2 条及以上可合并（录制中的记录不可参与）
- **文本级合并**：按创建时间顺序拼接转写文本（带【第 N 段】标记辅助 LLM），不重新转写音频
- 分段小结按 seq 顺延迁移、提问记录一并迁移；来源记录删除
- 合并后自动重新生成整体总结；主记录默认保留最早的一条

### 4. 录制暂停 / 恢复（刷新不丢失）

- 录制页新增「⏸ 暂停 / 继续录制 / 结束录制」控制
- **音频分片机制**：暂停关闭当前 webm 分片，恢复新建 MediaRecorder 开新分片（分片边界即完整转写断点，边界不丢音频）
- **刷新恢复**：暂停状态同时持久化在服务端（`is_paused` 字段）与本地 sessionStorage；刷新后显示恢复横幅，可「继续录制」（重连续录，历史文本播种、不重复转写）或「结束录制」（REST 收尾生成总结）
- 暂停中的记录**豁免僵死清理**（10 分钟无更新不误判为失败）
- 已录时长持久化，恢复后原样还原

### 5. 上传转写 GPU 加速

- 上传录音的中文/粤语转写切换至 **SenseVoice CUDA EP**（GPU），速度提升数倍
- 实时录制的窗口转写保持 CPU（低延迟优先，GPU 留给大文件）
- CUDA 初始化失败自动回落 CPU，不影响可用性
- 实现要点：sherpa-onnx CUDA 轮子（+cuda12.cudnn9）双 provider 实例、补齐 nvrtc/cufft 等 CUDA 运行库

### 6. 可选自动总结开关

- 上传/实时录制表单新增勾选（默认开启），随记录存储（`auto_summary` 字段）
- 关闭时转写完成即止（「已转写」状态），不调用 LLM
- 详情页对无总结记录提供「✨ 生成课堂总结」按钮，也可对已有总结的记录重新生成

### 7. 应用内更新服务（本版本核心基建）

- 后端：`GET /api/app/check-update`（免登录）读取 `data/apk/version.json`，与本地 versionCode 比较判断更新；`data/apk/` 静态挂载提供 APK 下载
- 安卓：自定义 `AutoUpdatePlugin`（版本查询、安装权限检查、下载进度回调、FileProvider 发起系统安装器），Manifest 增加 `REQUEST_INSTALL_PACKAGES`
- 前端：启动时自动检查（仅安卓原生环境生效），弹窗展示版本号与更新日志、下载进度条；`force` 字段支持强制更新；头部 ⤓ 按钮手动检查
- 「以后再说」本版本不再打扰，冷启动重新提示

## 三、非功能需求

| 维度 | 要求 |
|---|---|
| 兼容性 | 全部新功能向后兼容，无破坏性数据变更（新列均自动迁移） |
| 健壮性 | CUDA 不可用回落 CPU；暂停边界不丢音频；分享 token 不可预测（secrets.token_urlsafe） |
| 更新体验 | versionCode 与发布 tag 同步递增；APK 服务器托管，更新服务自举 |
| 轻量化 | APK 维持 4MB 量级 |

## 四、版本内修复的关键 Bug

| 问题 | 根因 | 修复 |
|---|---|---|
| 实时连接出错（后端崩溃重启） | SenseVoice（encoder-decoder）不支持热词，传入触发 C++ 层 abort | 中文路径移除热词，热词仅 Whisper 路径生效 |
| 分享链接打开报 500 | 响应 schema 字段名 `expires_at` 与模型 `share_expires_at` 不一致 | 手动构造响应对象 |
| 刷新后分享面板丢失撤销按钮 | 分享状态仅存组件临时 state | 依据后端 `share_expires_at` 恢复状态 |
| 合并后分段小结丢失 | 仅改外键时 delete-orphan 级联仍按内存集合删除子记录 | 通过集合移动（remove + append）迁移 |
| 暂停后恢复转写中断 | MediaRecorder.resume() 续写的裸 cluster 缺 webm 文件头无法解码 | 暂停时彻底 stop（等待冲刷），恢复时新建 MediaRecorder |

## 五、Release 信息

- **Tag**：`v0.3.0`
- **APK**：`classrecord-0.3.0.apk`（4.0MB），服务器托管于 `/downloads/apk/`
- **升级说明**：本版本为应用内更新服务的**引导版本**——当前 v0.2.0 用户需最后手动安装一次（浏览器打开下载链接或 adb install），之后所有更新均可在 App 内完成
- **更新日志**：

```
记录重命名与限时分享链接
记录合并（中断分段一键拼合）
录制暂停/恢复（刷新不丢失）
上传转写 GPU 加速
可选自动总结开关
应用内更新服务
```

- **已知限制**：
  - 刷新发生在「正在录制（未暂停）」时，浏览器已释放麦克风，中间音频无法找回（可用合并功能把补录片段拼回）
  - 分享链接为明文 URL 访问，任何持链接者在有效期内均可查看（无二次鉴权）
